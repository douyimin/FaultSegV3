# Figure provenance

The JPEGs in this directory are unmodified copies of the figures supplied with the manuscript **FaultSegV3: Less Is More in Seismic Fault Segmentation**. README captions are condensed from the manuscript; performance highlights are drawn from its open-source/commercial-method comparison.

| Repository asset | Manuscript source | Content |
| :--- | :--- | :--- |
| `architecture.jpg` | `00.jpg` | Network architecture |
| `study-overview.jpg` | `01.jpg` | Design hypothesis and experimental evidence |
| `few-volume-generalization.jpg` | `02.jpg` | Complete two-/five-volume training sets and field predictions |
| `data-scaling.jpg` | `03.jpg` | Training-set-size experiment |
| `capacity-scaling.jpg` | `04.jpg` | Width scaling and training dynamics |
| `field-f3.jpg` | `05.jpg` | F3 polygonal-fault comparison, qualitative only |
| `field-usgs1.jpg` | `06.jpg` | USGS1 comparison |
| `field-usgs2.jpg` | `07.jpg` | USGS2 comparison |
| `field-usgs3.jpg` | `08.jpg` | USGS3 comparison, qualitative only |
| `field-nlog.jpg` | `09.jpg` | NLOG comparison, qualitative only |

`banner.svg` is an editable vector banner made for the repository. Its reflection lines are a decorative schematic and do not represent measured seismic data or model predictions.
